# Report Generator

Модуль отвечает за генерацию итоговых отчётов проверки BGP-политик.  
Поддерживаются форматы CSV, Markdown, JSON и YAML.

Модуль агрегирует инциденты, статистику BGP-сессий и формирует удобные для анализа отчёты.

---

## Назначение

- Экспорт результатов проверки BGP-политик
- Формирование человекочитаемого Markdown-отчёта
- Генерация структурированных данных для автоматической обработки
- Централизованное управление всеми форматами отчётов

---

## Основные функции

### write_reports

Основная точка входа для генерации отчётов.

**Описание**

Функция всегда создаёт CSV и Markdown отчёты.  
JSON и YAML создаются только при включённых флагах в конфигурации.

**Аргументы**

- policies — список политик AS, полученных с Route Server
- incidents — список обнаруженных инцидентов
- config — объект конфигурации проекта
- bgp_stats — агрегированная статистика BGP-сессий

**Поведение**

- Формирует CSV-файл со списком инцидентов
- Формирует Markdown-отчёт со сводкой и деталями
- При необходимости вызывает генерацию JSON и YAML
- Выводит информацию о созданных файлах в stdout

---

### write_yaml_report

Генерация отчёта в формате YAML.

**Описание**

Создаёт YAML-файл с полной структурой результатов анализа.

**Содержимое**

- summary  
  - total_policy_peers — количество пиров из политики  
  - total_incidents — количество инцидентов  

- bgp_sessions_summary  
  - afi — статистика по IPv4 и IPv6  
  - total_sessions — общее количество BGP-сессий  
  - other_sessions — сессии с неизвестным AFI  

- incidents — полный список инцидентов  

- notes — пояснения и допущения анализа  

**Особенности**

- Поддержка Unicode
- Человекочитаемый формат
- Удобен для последующего анализа

---

### write_json_report

Генерация отчёта в формате JSON.

**Описание**

Создаёт JSON-отчёт для интеграций и автоматической обработки.

**Особенности**

- Обогащает инциденты
- Raw-данные JunOS преобразуются в строковое описание
- Используется форматирование с отступами
- Поддерживается Unicode

---

## Формат CSV-отчёта

CSV-файл содержит одну строку на каждый инцидент.

**Поля**

- router — имя маршрутизатора
- peer — IP-адрес BGP-соседа
- issue — тип инцидента
- remote_as — фактический ASN соседа
- expected_as — ожидаемый ASN по политике
- afi — адресное семейство
- state — состояние BGP-сессии
- details — дополнительные сведения

---

## Формат Markdown-отчёта

Markdown-отчёт предназначен для просмотра человеком.

### Summary

- количество пиров из политики
- количество найденных инцидентов

### BGP Sessions Summary

- статистика по IPv4 и IPv6
- разбивка по состояниям:
  - Established
  - Active
  - Connect
  - Idle
- соотношение:
  - without_policy / with_policy

### Incidents

Для каждого инцидента отображается:

- маршрутизатор
- IP пира
- тип проблемы
- фактический и ожидаемый ASN
- AFI
- состояние BGP
- краткое описание деталей

### Notes

- приватные ASN исключаются из анализа
- network и broadcast адреса помечаются как подозрительные
- при отсутствии netmiko SSH-проверка не выполняется

## Используемые зависимости

- csv — экспорт инцидентов
- json — генерация JSON-отчёта
- yaml — генерация YAML-отчёта
- typing — аннотации типов
- Config — централизованная конфигурация проекта

---

## Роль в архитектуре проекта

Модуль report_generator является финальным этапом обработки данных:

1. Получение политик AS
2. Сбор BGP-сессий с маршрутизаторов
3. Сравнение и анализ
4. Генерация отчётов

Модуль не выполняет сетевых операций и не участвует в логике анализа — он отвечает только за представление результатов.
